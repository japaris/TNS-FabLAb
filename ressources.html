CSV (Google Sheets) Markdown
Pour importer un modèle : Google Sheets → Fichier → Importer → Télécharger. Supprimez la ligne d'exemple après import.
Les versions Markdown peuvent être collées dans Apple Notes ou importées dans Notion.
Ne stockez jamais vos mots de passe dans un fichier. Utilisez un gestionnaire (ex : Bitwarden, 1Password, iCloud).
