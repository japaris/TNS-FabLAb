# TNS-FabLab

Atelier pour apprendre à créer des sites web et de petites apps sans être développeur.
L'objectif est d'aider les membres de la Triple Nine Society à se débrouiller seuls
avec leurs propres projets, en partant d'exemples simples et modifiables.

## Liens
- Accueil (GitHub Pages) : https://japaris.github.io/TNS-FabLAb/
- Exemple Claire : https://japaris.github.io/TNS-FabLAb/exemples/claire-location/
- Ressources : https://japaris.github.io/TNS-FabLAb/ressources.html

## Contenu
- exemples/ : mini projets à copier et personnaliser
- exemples/claire-location/ : site vitrine pour une location saisonnière

## Démarrer vite
1) Ouvrir le dossier de l'exemple.
2) Double-cliquer sur `index.html` pour un rendu rapide, ou lancer un petit serveur local.

Serveur local (optionnel, mais recommandé pour les liens et les pages multiples) :
- macOS / Linux : `python3 -m http.server` puis ouvrir http://localhost:8000

## Exemples
- `exemples/claire-location/` : pages descriptif, photos, disponibilités (Google Calendar) et contact.
