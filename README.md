# TNS-FabLab

Atelier pour apprendre a creer des sites web et de petites apps sans etre developpeur.
L'objectif est d'aider les membres de la Triple Nine Society a se debrouiller seuls
avec leurs projets, en partant d'exemples simples et modifiables.

## Contenu
- exemples/ : mini projets a copier et personnaliser
- exemples/claire-location/ : site vitrine pour une location saisonniere

## Demarrer vite
1) Ouvrir le dossier de l'exemple.
2) Double-cliquer sur `index.html` pour un rendu rapide, ou lancer un petit serveur local.

Serveur local (optionnel, mais recommande pour les liens et les pages multiples) :
- macOS / Linux : `python3 -m http.server` puis ouvrir http://localhost:8000

## Exemples
- `exemples/claire-location/` : pages descriptif, photos, disponibilites (Google Calendar) et contact.
