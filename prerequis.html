Pré-requis pour l'atelier.

Tout ce qu'il faut préparer pour que l'atelier aille vite : comptes, outils et contenus de base.

Objectif

Arriver avec tout prêt pour se concentrer sur le contenu et la méthode.

On évite les blocages techniques.

Comptes Logiciels Contenu

Comptes à créer

Compte Google

  • Obligatoire pour Gemini Code Assist
  • Utile pour Google Calendar et Docs

Compte GitHub

  • Utile pour publier avec GitHub Pages
  • Optionnel si vous ne publiez pas

Logiciels à installer

VS Code

  • Éditeur gratuit et simple
  • Permet d'ouvrir les fichiers HTML

Gemini Code Assist

  • Extension VS Code
  • Connexion avec compte Google

Contenu à apporter

Photos

  • 5 a 10 photos
  • Format JPG ou PNG

Texte

  • Presentation courte (10-15 lignes)
  • Une phrase d'accroche

Infos pratiques

  • Coordonnées de contact
  • Liens utiles (calendar, formulaire)
Astuce : préparer les photos dans un dossier unique pour gagner du temps.
