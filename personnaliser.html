Personnaliser Site Claire Rendez-vous

Personnaliser un exemple en 30 minutes.

Ce guide est fait pour les non-développeurs. Il suffit de suivre les étapes ci-dessous, sans installation complexe.

Ouvrir l'exemple Retour à l'accueil

Ce dont vous avez besoin

Un ordinateur, quelques photos et 20 à 30 minutes pour adapter le texte.

Optionnel : un calendrier Google pour les disponibilités.

Étapes Checklist

Étapes clés

1. Dupliquer un dossier Copier `exemples/claire-location/` et renommer le dossier avec votre projet.
2. Modifier les textes Ouvrir les fichiers HTML et remplacer les titres et paragraphes.
3. Remplacer les photos Mettre vos images dans `assets/photos/` puis mettre à jour les balises ``.
4. Ajouter le calendrier Copier le lien "Intégrer le calendrier" depuis Google Calendar et le coller dans `disponibilites.html`.
5. Mettre vos coordonnées Remplacer téléphone et email dans `contact.html`.
6. Publier Pousser sur GitHub et activer GitHub Pages pour obtenir un lien public.

Checklist rapide

Avant publication

  • Tous les textes relus et actualisés.
  • Photos légères (moins de 1 Mo chacune).
  • Liens testés entre les pages.

Calendrier

  • Calendrier Google créé et partagé en public.
  • Fuseau horaire correct (ex : Europe/Paris).
  • URL intégrée dans l'iframe.

Contact

  • Email testé et fonctionnel.
  • Indiquer les délais de réponse.
  • Option : formulaire externe (Google Forms).
Astuce : si vous changez beaucoup de texte, faites une recherche "Maison Claire" pour remplacer par le nom de votre projet dans tous les fichiers.
